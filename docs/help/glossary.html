HYDRUS variable names

The tooltips name the variables of the HYDRUS-1D input files (e.g. hCritA, TolTh, dtMin, iKappa, lFluxOut, TauW), so that the HYDRUS-1D manual Šimůnek et al. (2009); Šimůnek et al. (2013) can be used alongside this help.
