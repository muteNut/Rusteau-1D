Reference

Keyboard and mouse

Keyboard

KeysAction
F1help on the current page (in the Rosetta dialog: help on Rosetta; in the figure window: help on the figure editor)
F5run the calculation
Ctrl+Nnew project
Ctrl+Oopen a project
Ctrl+Ssave
Ctrl+Shift+Ssave as
Ctrl+Aselect all nodes (soil profile editor)
Alt+← / Alt+→back / forward in the help window
Enterconfirm a number typed into a field

On macOS, Cmd works in place of Ctrl.

Number fields

Click a field to type a value; drag it with the mouse to change the value continuously. A comma is accepted as decimal separator and d / D as exponent (1d-3). Characters that cannot be part of a number are ignored while typing (whole-number fields: digits and the minus sign only).

Plots

MouseAction
hovershows the values of the curve under the pointer
dragpans the plot
scroll wheelpans
Ctrl+scrollzooms
double-clickresets the axes
click on a legend entryshows or hides the curve

Figure editor

MouseAction
hover over the previewthe values of the axes of the panel under the pointer in the status bar
click on a panelselects the panel for the settings
click / right click (with Place with the mouse)moves the selected annotation / sets the end of an arrow
click on a symbol (Symbols and markup)copies it; Ctrl+V pastes it into a text

Soil profile editor

MouseAction
drag (tool Select nodes)selects a depth range
clickselects one node; for material and sub-region the whole layer
Shift+clickextends the selection
click (tool Observation nodes)adds an observation node, or selects the one under the pointer
drag (tool Observation nodes)moves the observation node to another node
double-click / Delete (tool Observation nodes)removes the observation node
click (tool Fixed points)adds or removes a fixed point
wheel / Ctrl+wheel / double-clickscroll / zoom / whole profile

Drag and drop

Drop a .h1dr, a HYDRUS-1D .h1d or a HYDRUS-1D project folder onto the window to open it.
