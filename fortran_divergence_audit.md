## A. Port follows the source
- `set_bc` lMinStep triggers, `wat_flow` iteration logic, Kool-Parker `Hyster`, `MatIn/GenMat/SetMat`, `Update` with `lExtrap`.
- **TmCont:** `dt`, `dtOpt`, `dtMax`, `dMul`, `dMul2`, `dtMin` REAL*4, `t` double (every value assigned to `dt`/`dtOpt` rounded to f32, also the `amax1(dt/3,dtMin)` retries); `iStep = anint(sngl(tFix-t)/dt)`; evening-out only for `1 <= iStep <= 10`; a single remaining step > dtMax + dtMin is halved also with a meteo file (4.17 EnBal2b: 0.011 -> 2 x 0.0055).
- **Hysteresis iModel 0:** Qm = Qs (MATERIAL.FOR). **Free-drainage bottom:** storage term kept.
- **Lenhard:** `SARWI = (thsD - thsW)/(thsD - thrD)` (4.17 Test10: 0 problems).
- **Vapor `ConVapor`:** no lLimit (`Hr = 1e-6` line is commented out in the source; 4.17 EnBal2b agrees).
- **Solute:** pulse ends at tPulse only for `.not.AtmBC`; at TLevel = 1 the full new-level top flux is booked.
- **TLInf records:** Solute<i>.out / Run_Inf.out lines at every printed level, the T_Level line only with `lWat.or.TLevel.eq.1.or.lEnd` (results keep one record per printed level: steady-water runs 3SELIM/TEST3/4/5/3LAIJURI).
- **Vapor volume:** the T_Level volume (TLInf) holds no vapor; the initial SubReg call comes before ThVNew is set, so the initial W-volume holds no vapor (WatBalT carries the initial vapor volume, first In-flow = -vapor/dt; 4.17 EnBal2b 6.5337 / -0.22724 at t = 328, TEST11 WatBalR). Test `vapor_volume_in_the_balance_and_time_level_output`.
- **VaporContent capacity term `ThetaV*xMol*g/R/TKelv*xConv`** (dThetaV/dh needs `/xConv`; right only for m): kept, so vapor runs depend on the length unit (`convert_units` check, cm/d -> m/h: EnBal2b cum vTop 3.4 %, surface T up to 1 C; TEST11 vBot 0.7 %; all other Direct examples within 1e-3 except 1DRAINAG 0.3 % and chaotic 1INFILTR).
- Comparison only: precision floor 1e-4, Temp only with heat, HeatVol not compared, first In-flow record, node-1 Flux, Depth tolerance, WatBalT/CncBalT + 1e-5 x volume, print quantum, old T_LEVEL layout, NObs = 0; Nod_Inf/Balance records matched to the nearest simulated time (print times 1, 1.001, 1.002 lie within one print-rounding window).

## B. Deviations from the 2009 source, all confirmed by HYDRUS 4.17
1. **Initial `lMinStep = .false.`** (1SCALING: 0.01, 0.023, 0.0399, ...; 1220 levels).
2. **Infiltration with a constant-flux top** (`KodTop = -1`, vTop < 0) booked in sum(Infil) (1SCALING 40.0 at 2400).
3. **Sub-region W-volume = mobile water only** with dual porosity (Test9/TEST9a region 1 = 2.0599 at t = 0).
4. **Heat top BC:** no extra `min(0,HeatFl)` term (4HEAT, 5SEASON).
5. **Heat top flux without energy balance:** `HeatFl = Cw*(tTopA(t-dt)*vOld(N) + tTopA(t)*vNew(N))/2`, same weighting for the vapor part (source: tTopA(t) for both; 5SEASON Temp 0.1-0.9 C low with it).
6. **TempAdj interior nodes:** `vVGrad = (vV(i+1)-vV(i-1))/(x(i+1)-x(i-1))` without the factor 2 (TEST11: 81 -> 8 problems).
7. **Runoff only with a head top** (`KodTop > 0`); with a flux top rTop - vTop is storage, not runoff (5SEASON: 4.17 prints 0 where the source gives 1.56e-3 at t = 95.01).
8. **Relative solute balance error:** `DeltC` (solute 1) only in CncBalR of solute 1, the other solutes use cCumA alone (source: DeltC of solute 1 for all; TEST3 CncBalR2 0.252 % at t = 50; ROOTUPTK_ACT2 CncBalR2 0.069 %, own DeltC would give 0.0136 %).
9. **Energy balance + vapor flow:** the latent heat carried through the surface by the soil vapor flux is given back to the top node, `F(N) = F(N) - HeatFl + xLat(TempN(N))*(vVNew(N)+vVOld(N))/2` (source: `-HeatFl` only). EnBal2b 231 -> 1; with observation nodes at 0/0.5/1/2 cm all temperatures agree to 0.001 C, 1623 time levels as in 4.17; without vapor flow source and 4.17 agree. Test `energy_balance_vapor.rs`.
10. Older, not re-checked (CHANGELOG): interception with daily meteo, dual-NEq gas decay columns, 2nd colloid site rates, iRelHum with energy balance, Evapor day number, Lenhard no-path branch.

## D. HYDRUS 4.17 features (not in the 2009 source)
- **Triggered irrigation** (`lIrrig` = 7th logical of `lSnow lHP1 lMeteo lVapor lActiveU lFluxes lIrrig`; record `Node Pressure Irrig_rate Duration Lag_period` after the bottom BC records; Irrig.out). Rules from the 4.17 run 5SEASON_IRR (5 events, all times agree; 2 problems left: sum(Infil)/sum(Evap) after t = 226, booked by the sign of vTop ~ +-1e-6): trigger at the first time level with h(obs node) < threshold, not again before the end; start = trigger + lag, end = start + duration, both time levels with an A_Level line; rTop = |rSoil| - rate (Prec of the record unchanged); an atmospheric record read meanwhile sets its own rTop, the end sets rTop = |rSoil| until the next record; at start, end and every record time between trigger and end lMinStep is assigned (not or-ed) from the change made by the irrigation. Option `IrrigationMode::FullDuration` (not 4.17): the rate is added to the precipitation for the whole duration, across records; the legacy reader always sets `Hydrus417`. Tests `triggered_irrigation.rs`, `irrigation_record.rs`.

Rust-only feature: boundary-condition cycles count the cycle from `t + 0.001*dt` (the time reaches a record time only within the synchronisation tolerance, e.g. 5.9999999925 for 6).

## G. Hysteresis.in, Options.in (10 Oct)
- **Hysteresis.in** (HysterIn, iHyst 1/2): 2 header lines, then `n ThOld Kappa` per node in internal order (bottom first, n unused); ThNew = ThOld, Kappa = KappaO, `Hyster(..., TolTh = -1)` reverses every node -> scanning curve of the opposite direction through (hOld, θ). Read/written by the legacy io, kept in `Profile::hysteresis` (dropped on regrid). Deviation: ConO is 0 in the source at that point (drying K curves vanish with iHyst 2); Rust uses K stored with a Rusteau restart, else the main curve of the given direction. With lInitW the source uses θ as hOld -> validation error. Test `hysteresis_restart.rs` (θ(t=0) = file θ to 1e-16; restart vs. uninterrupted run 7e-3 / 4e-3).
- **Options.in:** opened by HYDRUS.FOR (unit 35, err -> continue) and never read in both source versions (user's 2009 copy and phydrus 4.08); format undocumented (manuals 4.08/4.17). The options behind it are ported (`AdvancedOptions`, native project only, legacy save warns): lExtrap, iEnhanc, TauW (Rate in Reset storage/F2 and the ThNew update), lCentrif/Radius (CosAlf = ω²/g from rpm; SetBC: hBot column = speed (rpm in Rust), hBot = 0), lDensity (fRo polynomials, defaults 1 + 0.75c / 1). Deviations: TauW convergence test without Rate (the source accepts large dh once Rate is small; infiltration example diverged to 1e10 at τw = 0.05 d); centrifuge in conservative form with element-midpoint G (source form leaks 0.001 cm/h at equilibrium, 8 % balance error after 200 h); NodOut depth not shifted by Radius. lDensity kept as in the source (ρ∂θ/∂t, balance sums ρθ: WatBalT = ∫θ(ρ−ρ0)). Not with dual permeability. Test `advanced_options.rs` (centrifuge equilibrium = analytic, balance 0).
- **dtMin** rounded to f32 at init (REAL*4): `1e-7 as f32 > 1e-7` let a failed iteration retry forever at dt = dtMin.
- Not ported (decision): HP1, UnsatChem.
