# Keyboard and mouse
keywords: keyboard shortcuts; hotkeys; mouse; F1; F5; Ctrl+S; plots; zoom; profile editor

## Keyboard

| Keys | Action |
|---|---|
| F1 | help on the current page (in the Rosetta dialog: help on Rosetta; in the figure window: help on the figure editor) |
| F5 | run the calculation |
| Ctrl+N | new project |
| Ctrl+O | open a project |
| Ctrl+S | save |
| Ctrl+Shift+S | save as |
| Ctrl+A | select all nodes (soil profile editor) |
| Alt+← / Alt+→ | back / forward in the help window |
| Enter | confirm a number typed into a field |

On macOS, Cmd works in place of Ctrl.

## Number fields

Click a field to type a value; drag it with the mouse to change the value continuously. A comma is accepted as decimal separator and `d` / `D` as exponent (`1d-3`).

## Plots

| Mouse | Action |
|---|---|
| hover | shows the values of the curve under the pointer |
| drag | pans the plot |
| scroll wheel | pans |
| Ctrl+scroll | zooms |
| double-click | resets the axes |
| click on a legend entry | shows or hides the curve |

## Figure editor

| Mouse | Action |
|---|---|
| hover over the preview | the values of the axes of the panel under the pointer in the status bar |
| click on a panel | selects the panel for the settings |
| click / right click (with *Place with the mouse*) | moves the selected annotation / sets the end of an arrow |
| click on a symbol (*Symbols and markup*) | copies it; Ctrl+V pastes it into a text |

## Soil profile editor

| Mouse | Action |
|---|---|
| drag (tool *Select nodes*) | selects a depth range |
| click | selects one node; for material and sub-region the whole layer |
| Shift+click | extends the selection |
| click (tool *Observation nodes*) | adds an observation node, or selects the one under the pointer |
| drag (tool *Observation nodes*) | moves the observation node to another node |
| double-click / Delete (tool *Observation nodes*) | removes the observation node |
| click (tool *Fixed points*) | adds or removes a fixed point |
| wheel / Ctrl+wheel / double-click | scroll / zoom / whole profile |

## Drag and drop

Drop a `.h1dr`, a HYDRUS-1D `.h1d` or a HYDRUS-1D project folder onto the window to open it.
